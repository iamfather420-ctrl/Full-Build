# SAT Witness Migration

> **Current status: INCOMPLETE / BLOCKED.** The committed DFRL SMT assertions are not a 88-case SAT-witness corpus: the latest authoritative CI execution returned UNSAT for all 88 DFRL assertions. The registry had incorrectly labelled those assertions as SAT. The source metadata and verifier are being corrected to match the actual encoded queries. This does not complete the 120-case SAT-witness migration.
>
> The DH verifier still does not extract concrete SAT models or independently re-assert witnesses. Any DH SAT case therefore remains unverified. Do not use the historical native-Z3 note below as evidence that the current WASM verifier has completed the migration.


This build changes the 120-case formal corpus from contradiction/refutation
propositions to explicitly bounded, witness-oriented propositions.

## Authoritative target

- DFRL: 88/88 cases use satisfiable bounded witness SMT propositions.
- DH: 32/32 cases use satisfiable bounded witness SMT propositions.
- Expected Z3 result: `sat` for all 120 cases.
- The historical paradox/antinomy remains in the case metadata; the SAT
  proposition is explicitly documented as a bounded witness formalization and
  must not be presented as proof that the unrestricted historical paradox is
  consistent.

## Verification requirements

The authoritative commands remain:

```text
npm run verify:dfrl
npm run verify:dh-formal
npm run verify:120
```

The verifiers now require SAT results, fresh-context replays, concrete model
extraction, independent witness checking, mutation sensitivity, failure
injection, and tamper detection.

## Important

The source package was modified here, but a fresh Z3 execution has not been
claimed by this migration note. The machine-generated evidence artifacts must
be regenerated by running the authoritative verification commands in an
environment with the project's declared dependencies installed.

Do not edit generated evidence JSON to make the result SAT.


## Fresh native-Z3 recheck (2026-10-10)

A separate local recheck executed all 120 source propositions using the system
Z3 C API (Z3 4.13.3.0): DFRL 88/88 SAT, DH 32/32 SAT, 0 UNSAT, 0 UNKNOWN,
0 errors. All 120 fresh-context replays matched; all 120 models were extracted
and re-asserted in fresh contexts as SAT; and adding an explicit contradiction
made all 120 mutated cases UNSAT. The machine-readable report is
`artifacts/native-z3-sat-witness-recheck.json`.

This is independent corroboration of the source SMT corpus, **not** a substitute
for running the project's own `npm run verify:dfrl`, `npm run verify:dh-formal`,
and `npm run verify:120` against its declared `z3-solver` WASM dependency. Those
commands could not be run in this environment because the npm dependencies are
not installed and the package registry was unavailable. The older generated
reports still show the pre-migration UNSAT results; they are historical/stale
and must be regenerated by the authoritative scripts, not edited by hand.
