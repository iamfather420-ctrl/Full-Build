# Berkeley FrameNet (contextual semantics): inclusion assessment

**Reviewed:** 2026-11-25. **Recommendation: HUMAN_LICENSE_REVIEW; do not import the corpus pending written clarification.** The best-supported stable data revision is Berkeley FrameNet 1.7, but the present official site does not name a newer or current downloadable revision. The site describes an English lexical database built from annotated examples in actual texts. It asks people to request a copy through a page titled “FrameNet Data Licensing Request”; that page requests the applicant’s role, including whether they work for a for-profit company, and provides no license grant or reuse terms. The project’s About page calls the data “freely available for download,” but that wording alone does not establish commercial reuse, redistribution, or modification rights. [1] [2] [3]

**License and exact component.** The NLTK Data catalog entry for the specific `framenet_v17` package names Collin F. Baker and labels it “Creative Commons Attribution 3.0 Unported License.” This is useful evidence about a third-party distribution, not confirmation from Berkeley that the full FrameNet 1.7 dataset—or every component in it—is licensed that way. Berkeley’s current request form calls itself a licensing request and publishes no terms. The discrepancy leaves the rights for this exact corpus package, including commercial use, redistribution, and modifications, unresolved. Do not treat “freely available” or NLTK’s catalog metadata as sufficient authority to mirror or sublicense the data. Ask Berkeley to confirm which license applies to the 1.7 XML/corpus data, whether it covers commercial repository redistribution and derivative subsets, and whether any text-source or other components have separate terms. This is an operational rights assessment, not legal advice. [1] [2] [5]

**Version and scope.** FrameNet’s current project-status page reports 1,224 frames, 13,749 lexical units, and 207,546 annotation sets, but does not identify those statistics with a dated release. [4] The FrameNet API paper documents `framenet_v17` as FrameNet 1.7, says it provides access to nearly all information in the release, and reports an 855 MB uncompressed footprint and thousands of XML files. [6] NLTK’s catalog gives the compressed package size as 99,207,152 bytes (about 94.6 MiB). I checked the pinned archive’s HTTP metadata only; no archive was downloaded. The 2017 paper and package identifier establish 1.7, while the Berkeley site’s current public news and request/download pages do not advertise a later numbered data release. Thus, “1.7” is the latest stable release evidenced by the sources checked on this review date, not a version statement on the current Berkeley site. [2] [3] [5] [6]

**Acquisition pointer and feasibility.** Berkeley’s official route is its [data-licensing request form](https://framenet.icsi.berkeley.edu/data-request); the download page presents a ZIP action after token validation rather than a public static archive URL. A directly accessible, commit-pinned *NLTK mirror* is [framenet_v17.zip](https://raw.githubusercontent.com/nltk/nltk_data/28566795e44a265c02c9f60f9743ecdf4ec79242/packages/corpora/framenet_v17.zip) (99,207,152 bytes; package-file commit `28566795e44a265c02c9f60f9743ecdf4ec79242`, dated 2016-12-30). This is a reproducible pointer, not an endorsement of the mirror’s licensing or an official Berkeley download. The scope is technically manageable for a local controlled review, though an uncompressed 855 MB is substantial for a source repository; the primary blocker is rights, not transfer size. [2] [3] [5] [6]

**Repository handling.** Keep identifiers and provenance intact if rights are later cleared: retain FrameNet’s version label (1.7), source identifiers/IDs in the XML, original file structure where possible, the Berkeley project citation, and a record of any transformations and file hashes. Do not conflate this English resource with other FrameNets or assume those projects share its terms. No corpus was acquired, no repository was changed, and the six existing Library of Congress books were left untouched.
